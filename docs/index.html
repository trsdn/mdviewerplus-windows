Help

In MDViewer+, press F1 or choose Help → MDViewer+ Help. The About screen identifies the installed edition and version.

Common shortcuts: Ctrl+O opens a file, Ctrl+S saves, Ctrl+F finds, and Ctrl+E changes the view.

Folder Navigator

Choose File → Open Folder…, then toggle the navigator with Ctrl+Shift+B. It is hidden by default and available in both editions. The read-only, local-only tree loads folders only as you expand them, reveals the current document, and supports arrow keys, Home, End, Enter, and Space.

The navigator excludes hidden items and symbolic links and is bounded to 12 folder levels, 500 children per folder, and 5,000 loaded nodes. Opening a file keeps the existing unsaved-change confirmation.

Choose an edition

Full is recommended and includes broad syntax highlighting, Mermaid diagrams, and YAML metadata. Lite is smaller and contains only its selected offline preview features.

Installing one edition replaces the other while preserving the same product identity.

Privacy and security

Documents are rendered locally. MDViewer+ does not use a CDN or download preview content at runtime. Installers are currently unsigned; download them only from the repository releases and verify the provided SHA-256 file.
